# خلاصه تنظیمات پروتکل مسافت ثابت

این فایل مشخصات اجرایی حالت Fixed-Distance را خلاصه می‌کند.

1. گام شبیه‌سازی `0.1 s` است.
2. هر اپیزود تا ۱۵۰۰ Tick اجرا می‌شود.
3. سرعت مرجع پاداش ۵۰ km/h است.
4. مسافت مرجع با رابطه `1500 × 0.1 × 50 / 3.6` محاسبه می‌شود: **۲۰۸۳٫۳۳۳ متر**.
5. آستانه ۹۵ درصد پیشروی برابر **۱۹۷۹٫۱۶۷ متر** است.
6. اپیزود با یک Spawn ID از CSV شروع می‌شود.
7. پیشروی از مؤلفه مثبت جابه‌جایی در امتداد Waypoint رانندگی به‌دست می‌آید.
8. مسافت و مقدار Completion در `training_log.csv` ثبت می‌شوند.
9. تنظیمات، نسخه محاسبه پیشروی و هش فایل Spawn در `training_config.json` ذخیره می‌شوند.
10. برای ادامه آموزش، Checkpoint باید با تنظیمات همان اجرا سازگار باشد.
